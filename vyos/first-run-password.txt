VyOS 1.4.0 — change existing vyos password at console.
1. configure
2. set system login user vyos authentication plaintext-password
   Follow the interactive prompt if available. Do not type the password as a CLI argument.
   If no interactive prompt appears, STOP and consult native help.
3. compare (ensure only intended password change)
4. commit
5. Test a SECOND login using the new password before disconnecting.
6. save
7. exit
Do not rename vyos or alter routes, NAT, interfaces, ICMP or scoring access.
