PAN-OS 11.0.2 — change existing admin password in native GUI.
1. From an authorized LAN workstation open https://172.20.240.200
2. Device > Administrators > admin; use the available password-change control.
3. Enter and confirm a NEW password; do not change username or privileges.
4. Commit if required. Verify a SECOND login in a separate browser session.
5. Record the password OFFLINE. Do not put it in GitHub.
No policy, NAT, interface, ICMP, or service changes in this procedure.
